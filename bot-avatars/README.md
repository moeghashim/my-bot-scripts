# bot-avatars

Sticker-style avatars for a set of Grok Bot assistants (uniform line weight and a white outer outline), one `<slug>.png` per bot, split into `personal/` and `work/` rosters.

`personal/` slugs: alfred, angel, calendar, capture, coder, contraptions, dining, disk, dot, experiences, finance, health, house, matchmake, maths, music, portal, routine, security, texts, things, tweets, writer, wubot.

`work/` slugs: alfrey, blocky, buggy, chief, coder, dashy, extendy, lexy, manny, melody, moldy, monie, nessy, perfy, portal, primmy, revvy, scouty, siggy, tinka. These are clay-style avatars on an opaque background rather than stickers.

`msg-graph` can show these: copy them into `msg-graph/avatars/` (gitignored) with file names matching your bot names.
