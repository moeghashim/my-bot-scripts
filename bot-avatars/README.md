# bot-avatars

Sticker-style avatars for a set of Grok Bot assistants (uniform line weight and a white outer outline), one `<slug>.png` per bot in `personal/`.

Slugs: alfred, angel, calendar, capture, coder, dining, disk-saver, finance, health, house, matchmake, maths, music, poker, routine, security, texts, things, tweets, writer, wubot.

`msg-graph` can show these: copy them into `msg-graph/avatars/` (gitignored) with file names matching your bot names.
